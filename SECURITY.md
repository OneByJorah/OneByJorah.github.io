# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Use GitHub's private vulnerability reporting (the **Security** tab, then **Report a vulnerability**) or email <info@jorahone.com> with:

- what you found and where
- steps to reproduce
- the impact you expect

You will get an acknowledgement within a few days. Fixes are released as patch versions and noted in the changelog.

## Supported versions

Only the latest release receives security fixes.

## Good practice for users

- Keep services bound to localhost or a private network.
- Never commit `.env` files or credentials.
- Pull the latest image before reporting an issue.
